# 直播推流模块（本仓库）

本目录说明如何与 **OBS**、**FFmpeg**、**SRS** 及云端 RTMP 域名配合，将「数字人画面 + 商品叠加层」推送到观众端。实际推流大多在主播机器上由 OBS 完成，本仓库提供配置思路与可编辑示例脚本。

## 推荐链路

1. 浏览器或本地渲染数字人 + 商品叠加（或 OBS「浏览器源」加载本前端页面 URL）。
2. OBS 将合成画面输出到**虚拟摄像头**或**窗口采集**。
3. OBS 推流至 **SRS**（或云直播的 RTMP 旁路），观众通过 HLS / WebRTC / RTMP 播放（由后端与 SRS 配置决定）。

## 多清晰度与弱网

- 在 OBS 中设置多组**输出**档案（如 480p / 720p / 1080p），按现场上行带宽手动或按规范切换。
- 云端可配合**转码模板**（阿里云 / 腾讯云）向观众下发多码率；主播侧仍建议限制上行码率，避免农村弱网丢包。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `srs/srs.conf.example` | SRS 最小示例片段，需按环境补全 `vhost`、鉴权等 |
| `scripts/push-rtmp.example.sh` | FFmpeg 将本地视频/测试源推至 RTMP（调试用） |
| `scripts/transcode-ladder.example.sh` | 多档位转码思路示例（需在具备解码能力的机器上运行） |

## 环境变量

复制仓库根目录 `.env.example`，填写推流地址与前端访问的后端 API / WebSocket 地址。切勿将真实密钥提交到 Git。
