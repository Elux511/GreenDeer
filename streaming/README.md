# 直播推流（立项口径：OBS + FFmpeg）

与架构图 **输出层「OBS 虚拟摄像头推流」**、**数据与基础设施层「FFmpeg」** 及选型表 **「业界通用、支持虚拟摄像头」** 严格对应。

---

## 分工（不要和架构图冲突）

| 层级 / 选型 | 承担内容 |
| --- | --- |
| **OBS 虚拟摄像头推流（输出层）** | 在主播电脑合成画面（含浏览器源：Vue **商品卡片叠加**、Live2D 页面等），通过 **虚拟摄像机** 输出为系统摄像头，供 **抖音 / 快手直播伴侣** 等采集后上传平台。农户侧主推路径。 |
| **OBS + FFmpeg（选型表「推流」）** | **OBS**：采集与合成、虚拟摄像头。**FFmpeg**：基础设施层 **媒体处理**（转封装、转码、拉流转推、脚本调试），多在服务器或运维脚本中使用，**不等于**替代 OBS 虚拟摄像头这一输出形态。 |

---

## 农户侧：OBS 虚拟摄像头（输出层）

1. OBS 场景中加入 **浏览器源**（本仓库前端 URL）与 **Live2D / 数字人画面** 等来源，完成 **商品卡片叠加** 与数字人合成。  
2. **工具 → 虚拟摄像机 → 启动**。  
3. 打开直播伴侣，**摄像头** 选择 **OBS Virtual Camera**。  
4. 在伴侣内开播（推流至平台由伴侣完成）。

详见立项材料中「虚拟摄像头」与弱网注意事项；勿要求农户同时使用多条上行编码浪费带宽。

## 基础设施侧：FFmpeg（数据与基础设施层）

用于 **媒体处理**：例如测试 RTMP 是否可达、拉流转推、多档位转码示例。

| 文件 | 说明 |
| --- | --- |
| [`scripts/push-rtmp.example.sh`](scripts/push-rtmp.example.sh) | 调试推流 |
| [`scripts/transcode-ladder.example.sh`](scripts/transcode-ladder.example.sh) | 多档位思路示例 |
| [`srs/srs.conf.example`](srs/srs.conf.example) | 若自建流媒体服务器时的配置片段（部署选型以课题组为准） |

---

## 与本仓库前端

- `npm run dev` 后，OBS **浏览器源** 指向对应页面即可参与 **商品卡片叠加**。  
- 推流密钥不进前端；`.env` 仅 API / WebSocket（仓库根目录 `.env.example`）。
